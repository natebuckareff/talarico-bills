# James Talarico — 16 Enacted Texas Laws (2019–2025)

A self-contained, accessible, responsive HTML page of the 16-law table. It links each bill to its official Texas Legislature Online legislative history. No build step, dependencies, frameworks, analytics, or external assets.

## Publish on GitHub Pages

1. Create a public GitHub repository (or open an existing one).
2. Upload `index.html` to the repository root, then commit. The other bundled files are optional data and documentation.
3. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Select **main**, select **/(root)**, and save.
5. Your page will be available at `https://YOUR-USERNAME.github.io/YOUR-REPO/` after GitHub publishes it. (For a repository named `YOUR-USERNAME.github.io`, it appears at the root domain instead.)

You can also simply open `index.html` locally in any modern browser. Search and filtering work without an internet connection; the bill-history links require internet access.

## Files

- `index.html` — complete website, including all styling and tiny client-side filter script
- `laws.csv` — same 16 records in portable tabular form, including official source URLs
- `README.md` — this guide

## Editorial notes

The page presents **lead House authorship** and **House sponsorship of Senate bills**, not sole authorship of all 16 bills. Bill descriptions summarize legal changes and intended effects rather than verified outcome estimates. The list is not an endorsement. Please consult the linked official histories and enrolled texts for legal details.
